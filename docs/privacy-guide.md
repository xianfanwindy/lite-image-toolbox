# 轻图工具箱隐私保护指引参考

本文根据当前源码整理，可作为在微信公众平台填写“用户隐私保护指引”的参考。微信后台的字段、类目要求和审核规则可能调整，提交前必须以后台当期显示的字段为准，并再次核对填写内容与实际发布代码一致。

## 数据路径

| 能力 | 用途 | 是否上传 | 保存位置 |
|---|---|---:|---|
| 选择相册图片 / 拍照 | 用户主动选择待处理图片 | 否 | 微信临时文件 |
| Canvas 处理 | 在本地完成压缩、尺寸调整、九宫格切图和文字水印 | 否 | 微信临时文件 |
| 写入相册 | 用户主动点击保存处理结果 | 否 | 用户系统相册 |
| Banner 广告 | 流量主开通后展示首页或结果页 Banner | 不接触用户图片 | 由微信广告组件处理 |

## 本项目不收集的信息

当前项目代码不收集、上传或建立数据库保存以下信息：

- 手机号；
- 头像和昵称；
- 位置；
- 设备 ID；
- 用户选择的原始图片及处理后的图片内容。

项目没有登录、服务器、云函数、外部 API 或历史记录数据库。选图和 Canvas 导出的文件均属于微信运行环境管理的临时文件；页面不建立图片历史数据库，也不提供跨设备同步。用户点击保存后，结果由微信能力写入用户自己的系统相册。

## 权限和广告说明

- 相册图片或拍照只在用户主动选图时使用。
- `scope.writePhotosAlbum` 只在用户主动保存处理结果时使用；如果用户取消或拒绝授权，项目不会写入相册，并允许用户稍后重新操作。
- Banner 默认关闭。只有 `config/ads.js` 配置了有效的 Banner unit ID 才会展示；广告加载失败时会隐藏，不阻断图片处理和保存。
- 项目代码不会把图片路径或图片内容传给 Banner 广告组件。微信广告组件自身的数据处理应按微信平台当期规则和后台提示披露，不能用本文替代平台要求。

## 后台填写参考

可根据微信后台当期字段，按以下真实用途组织说明：

- 选择图片 / 拍照：用于由用户主动选择需要在本机处理的图片。
- 保存到相册：用于由用户主动保存压缩、尺寸调整、九宫格切图或文字水印的结果。
- 图片处理方式：图片通过小程序 Canvas 在设备本地处理，不上传到项目服务器，也不建立历史记录。
- 广告：仅在已开通流量主且配置 Banner unit ID 后使用微信广告组件；项目代码不向广告组件提供用户图片。

发布前应同时检查 `app.json` 权限描述、`config/ads.js` 的实际发布值和微信后台隐私字段。任何后续功能如果新增数据收集、远程请求或权限，必须先更新代码审查、network gate 和本指引，再提交新版本。
